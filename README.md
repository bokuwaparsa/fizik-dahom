# فیزیک‌دهم 🎓⚡

**بازی آموزشی آزاد و رایگان برای فیزیک پایهٔ دهم (ایران)** — دقیقاً مطابق فهرست رسمی کتاب درسی، به فارسی و با رابط راست‌به‌چپ.

🔗 **سایت زنده:** https://bokuwaparsa.github.io/fizik-dahom/

## چیست؟

فیزیک‌دهم کل کتاب فیزیک ۱ (پایهٔ دهم) را به **۳۷ درس و آزمایشگاه تعاملی در ۵ فصل** تبدیل می‌کند:

| فصل | موضوع | درس‌ها |
|-----|-------|--------|
| ۱ | فیزیک و اندازه‌گیری | ۶ درس + پرسش‌های فصل |
| ۲ | ویژگی‌های فیزیکی مواد | ۵ درس + پرسش‌های فصل |
| ۳ | کار، انرژی و توان | ۷ درس + پرسش‌های فصل |
| ۴ | دما و گرما | ۶ درس + پرسش‌های فصل |
| ۵ | ترمودینامیک | ۸ درس + پرسش‌های فصل |

هر درس چهار گام دارد: **یاد بگیر ← آزمایشگاه ← تمرین ← آزمون**

- **یاد بگیر:** توضیح گام‌به‌گام با فرمول‌های واقعی (KaTeX)، جدول‌ها و مثال حل‌شدهٔ چندمرحله‌ای
- **آزمایشگاه:** شبیه‌سازی تعاملی canvas اختصاصی همان درس (کاوشگر مقیاس‌ها، حوض شناوری، لولهٔ ونتوری، پیستون گاز، نمودار P–V، جریان انرژی ماشین گرمایی و…)
- **تمرین:** پرسش‌های راهنمادار با یادآور و بازخورد فوری
- **آزمون:** آزمون استاندارد با نمرهٔ قبولی ۷۰٪ و ذخیرهٔ بهترین نمره

XP، مرحله، رتبه، نشان‌های ویژه و پیشرفتِ به‌تفکیک فصل — همه فقط در مرورگر شما (localStorage) ذخیره می‌شود.

## ویژگی‌ها

- ۱۰۰٪ فارسی و RTL (قلم وزیرمتن)
- ۳۲ آزمایشگاه تعاملی اختصاصی (HTML5 Canvas)
- بدون حساب، بدون تبلیغ، بدون ردیابی، بدون تماس شبکه‌ای بیرونی
- رعایت «کاهش حرکت» (prefers reduced motion) و دسترس‌پذیری (ARIA)
- تم روشن/تیره
- محتوای کاملاً اصیل — فقط فهرست موضوعات کتاب به‌عنوان چک‌لیست استفاده شده است

## اجرا

```bash
bun install
bun run dev          # حالت توسعه روی پورت 3000

bun run build:export # خروجی استاتیک برای GitHub Pages (پوشهٔ .next-static)
```
